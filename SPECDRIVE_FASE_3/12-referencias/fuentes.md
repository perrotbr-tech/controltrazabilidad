# Fuentes y ejemplos

Consulta: 2026-09-09.

## Fuente oficial

1. Biblioteca del Congreso Nacional de Chile. Decreto Supremo 80, Reglamento del transporte privado remunerado de pasajeros. Define servicio para pasajeros predeterminados, origen/destino, autorización, documentación, vehículos, conductores y fiscalización.
   https://www.bcn.cl/leychile/navegar?idNorma=230180

## Casos y plataformas

2. Vigatec. Caso de éxito BHP Minera Escondida. Declara control de asistencia de 4.000 colaboradores, marcaje fijo y móvil y PDA para ingreso a buses.
   https://www.vigatec.com/caso-de-exito/bhp-minera-escondida/

3. AllRide. Software de gestión de transporte de personal para minería. Describe reserva anticipada, lista de espera, right-sizing, abordaje, rutas fijas/dinámicas, offline, múltiples proveedores y operaciones con Antofagasta Minerals, SQM y otras.
   https://allrideapp.com/transporte-personal-mineria/

4. SmartPasajes. Software para transporte minero y faenas. Describe nómina autorizada, turnos, abordaje QR/RUT y asignación automática si hay cupos.
   https://smartpasajes.cl/software-transporte-minero

## Clasificación de evidencia

- Fuente 1: normativa oficial.
- Fuentes 2 a 4: declaraciones de proveedores sobre sus soluciones o clientes; útiles como referencia funcional, no como auditoría independiente.

## Preguntas para una demo de proveedor

- ¿Cómo reciben y versionan cambios frecuentes de turno?
- ¿Pueden configurar apertura T−24 y bloqueo T−2 por contrato?
- ¿Qué ocurre si el turno cambia después del cierre?
- ¿Cómo conservan manifiesto original y anexo?
- ¿Cómo previenen doble reserva y sobrecupo concurrente?
- ¿Cómo trabajanan lista de espera por rutas?
- ¿Funciona abordaje offline y cómo resuelve duplicados?
- ¿Cómo aíslan mandantes, contratistas y contratos?
- ¿Quién posee y exporta los datos?
- ¿Dónde se alojan?
- ¿Qué costo fijo, por usuario, por vehículo e implementación existe?
- ¿Qué SLA, soporte, reversibilidad y API ofrecen?
